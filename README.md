# ComfyUI-Qwen3ASR-MLX

ComfyUI custom nodes for Qwen3 Speech-To-Text(ASR) using Apple MLX backend.

This project targets for Apple sillicon chips only, easy steps for comfyui  audio(.wav) to subtitle(multiline) files generation.

[Qwen3-ASR](https://huggingface.co/collections/mlx-community/qwen3-asr)
